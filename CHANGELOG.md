# Changelog
All notable changes to this project will be documented in this file.

## [Unreleased]
### Added
- Initial scaffold.
- Власник щойно знайденої автоматизації визначається за головним contributor'ом
  репозиторію: адміністратор проставляє людині GitHub-логін на її сторінці, і
  скан віддає репозиторій їй. `AUTOMATION_SYNC_OWNER_EMAIL` лишається запасним
  варіантом. Потребує `flask migrate-github-username`.
- Адміністратор може передати автоматизацію іншому власнику прямо з її сторінки.
- Синк з GitHub читає необов'язковий `dashboard/metrics.json` (контракт:
  `docs/metrics-contract.md`): зберігає знімок кожного синку, опис метрик і заміри,
  які ніколи не перезаписуються. Невалідний файл нічого не змінює, лише пише подію в
  журнал. Один журнал подій для синків, змін метрик, підтверджень і ручних змін
  ROI-полів у формах картки й Stage 1. Адміністратор може підтвердити метрику на
  конкретному знімку (поки лише POST-маршрут, без інтерфейсу). Потребує
  `flask migrate-metrics`.
- Контракт метрик v1.1: синк приймає `value_items` (гроші за статтями: дохід,
  економія витрат, час, менше втрат, експлуатація) з формулою, поясненням і
  джерелом, `baseline.not_applicable_why` для «неможливо зміряти» і відкриті
  питання до статті (`value_item_id`). Валідатор збігається зі скілом
  stage-1-supplax на тих самих кейсах. На «Цінності» нова колонка «Цінність, $/міс»,
  таблиця статей у деталях і підтвердження статті адміністратором; вердикт
  скидається, якщо змінились сума, формула чи статус. Потребує
  `flask migrate-value-items`.
### Changed
- Сторінка «Цінність автоматизацій» рахує з `dashboard/metrics.json`: плитки за
  статусом головної метрики, гроші з розбивкою за вердиктом, таблиця «До → Ціль →
  Факт» з деталями, історією замірів, відкритими питаннями, журналом і формою
  підтвердження для адміністратора. За замовчуванням показує лише запущені
  автоматизації. Картки без файлу метрик рахуються по-старому з позначкою «старий
  формат», але «Виміряно» тепер означає число, а не текстову мітку.
